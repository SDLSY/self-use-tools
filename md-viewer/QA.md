# 验收清单

1.1.0 新增编辑与中性深灰夜间主题。`npm run test:editor` 验证分栏编辑、实时预览、手动保存、UTF-8 BOM/CRLF、标签草稿隔离、外部修改冲突取消/覆盖、重新载入、删除与只读文件保存失败、关闭标签/窗口保护、源文本搜索、夜间配色和小窗口布局。`scripts/verify-upgrade.ps1 -Installer release\MoYue-Setup-1.1.0-x64.exe` 验证连续升级后默认文件关联不丢失。

测试命令：先 `npm run build`，再 `npm test`。脚本通过 Playwright 启动真实 Electron，测试文件使用样例副本，独立用户配置目录，避免改动原始样例或个人设置。

| 范围 | 验证与证据 |
| --- | --- |
| 首次打开、中文及空格路径 | 命令行传入样例，断言标题和正文 |
| 表格、任务列表、高亮、公式、Mermaid | 断言实际渲染节点、图表文字、公式布局；保存截图 |
| 异常公式、错误图表、恶意 HTML | 断言错误提示与后续内容存在；无脚本执行、无 Node 访问 |
| 本地图片、重复标题、跨文档链接 | 断言图片加载、唯一锚点、标签数与标题 |
| 搜索、复制、目录、字号、主题 | 操作真实控件并检查结果；深浅色截图 |
| 文件选择、多文件拖入、去重 | 模拟原生文件选择器返回路径、CDP 原生文件拖放，断言标签数 |
| 修改、删除、恢复 | 外部修改副本、删除再写回；检查自动刷新、阅读位置和其他标签 |
| 单实例、关闭标签 | 实际启动第二个进程、检查现有窗口；点击与 Ctrl+W |
| 离线、只读 | 网络离线后刷新并检查本地资源；源文档 SHA-256 不变 |
| 设置持久化、最小尺寸 | 重启读取配置，760×520 下检查控件边界、截图 |
| 外部网页 | 拦截主进程 shell.openExternal 验证分发 URL，避免测试干扰浏览器 |
| 安装版 | 指定 MD_VIEWER_EXE 对安装后的 exe 运行同一套测试；另测 NSIS 可选关联注册及清理 |

测试结果与截图生成于 `test-results/`。自动化测试不能代替 Windows 默认应用确认界面的人工作业。
