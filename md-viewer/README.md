# 墨阅 · 本地 Markdown 桌面查看器

中文界面、支持 Markdown 编辑与实时预览、单窗口多标签的 Windows x64 桌面工具。

## 安装与打开

1. 运行 `release/MoYue-Setup-1.1.1-x64.exe`，选择安装目录。
2. 首次安装时，“关联 .md 和 .markdown 文件”默认不勾选。勾选后，墨阅加入 Windows 的“打开方式”和默认应用候选，不强行覆盖已有默认程序。1.0.2 起升级会保留已有的墨阅关联；升级中的卸载阶段不会移除其打开命令。
3. 若双击仍由其他程序打开：右键文档 → 打开方式 → 选择其他应用 → 墨阅 → 始终使用；也可在“设置 → 应用 → 默认应用”搜索 `.md` 和 `.markdown` 分别选择墨阅。
4. 打开墨阅后点击“打开文件”，可多选；也可把多个文件拖入窗口。命令行：`"安装目录\墨阅.exe" "D:\文档\中文 文件.md" "D:\文档\笔记.markdown"`。

程序已运行时，命令行、资源管理器或“打开方式”传入的文件会进入现有窗口。同一路径不重复开标签。关闭最后一个标签后回到欢迎页，关闭窗口退出程序。

安装程序未进行商业代码签名，Windows 可能显示发布者未知。安装不需要管理员权限，默认只安装到当前用户。卸载可从 Windows“已安装的应用”完成；卸载时清理墨阅的文件关联候选，保留用户阅读设置。

## 阅读操作

| 操作 | 方法 |
| --- | --- |
| 打开多个文档 | 顶部按钮、拖入文件、`Ctrl+O` |
| 切换与关闭标签 | 点击标签或 ×；`Ctrl+W` 关闭当前标签 |
| 编辑与预览 | 默认分栏，可切换“编辑 / 分栏 / 预览” |
| 保存修改 | `Ctrl+S` 或“保存”；未保存的标签显示圆点，关闭时可保存、放弃或取消 |
| 重新载入 | 读取磁盘版本；有未保存修改时需确认放弃草稿 |
| 文内搜索 | `Ctrl+F`；Enter 下一个、Shift+Enter 上一个、Esc 关闭 |
| 目录 | 点击“目录”显示或折叠，点击标题跳转 |
| 字号 | A− / A＋；`Ctrl+-` / `Ctrl++`，范围 12–28 |
| 主题 | 点击右上角 ◐ 切换深浅色 |
| 复制代码 | 代码块右上角“复制” |

支持常用 Markdown、表格、任务列表、删除线、代码高亮、`$...$` 行内公式、独立行 `$$...$$` 块公式、mermaid 围栏代码块。Mermaid 图表语法错误时保留源代码并提示；不会影响其他标签。文内搜索按正文文本节点匹配，不跨格式节点拼接；最多高亮 10,000 项。

## 文件、图片与刷新

- 文档按 UTF-8 读取（允许 BOM），单文件上限 20 MB。默认分栏编辑与实时预览，可切换为单独编辑或预览。Ctrl+S 或“保存”写入当前文件，保留已有 UTF-8 BOM 与换行方式；只读文件会提示保存失败。极大或复杂图表建议拆分文档。
- 本地相对图片从当前文档目录解析，仅允许当前目录和子目录中的常见图片格式；不允许绝对路径、目录穿越或符号链接绕出目录。请将共享图片放入文档目录的子目录。远程 http/https 图片需要网络。
- 标题锚点使用小写标题文本、空格换为 `-`，保留中文；重复标题依次添加 `-1`、`-2`。跨 Markdown 链接打开到新标签；相同文档复用标签。跨文档链接可带标题锚点。
- 网页 http/https 链接交给系统默认浏览器，其他协议和非 Markdown 本地附件链接会被拒绝。
- 监听已打开文件所在目录，没有未保存修改时，外部修改后自动刷新，尽量保留垂直滚动位置；编辑中的草稿不会被刷新覆盖，保存前会检查外部变更并请求确认。删除或移动后显示提示。文件恢复后自动重新读取。若目录被删除导致监听中断，请重新打开文件。
- 默认配置位置：`%APPDATA%\local-md-viewer\settings.json`（以系统实际应用数据目录为准），保存主题、字号和目录开关。不保存文档历史或正文。高级用户可用 `--user-data-dir=绝对路径` 隔离配置。
- 字体（Noto Sans SC）、高亮、公式、图表与样式随安装包分发，本地内容不依赖 CDN，不需要账号和网络。

## 安全设计

主进程读取并保存被打开的 Markdown；保存仅限已授权打开的文档 ID，不接受任意写入路径。渲染窗口禁用 Node.js，启用 sandbox、contextIsolation 与 webSecurity；preload 只提供文件选择/拖入、已打开文档链接、关闭标签、设置及文档通知接口。图片协议按已打开文档授权并校验真实路径；应用协议只暴露打包静态资源。渲染 HTML 经过 DOMPurify，禁止文档脚本、事件处理、任意样式、嵌入页面与危险链接；KaTeX 禁止信任扩展，Mermaid 采用 strict 模式。代码块只显示和复制，不执行。

## 源码与构建

需要 Windows x64、Node.js 24 和 npm。依赖均精确锁定，提交 `package-lock.json`。

```powershell
npm ci
npm run build
npm test
npm run test:editor
npm start
npm run dist
```

`npm start` 先编译再打开窗口。`npm run dist` 生成 NSIS 安装包与 `release/win-unpacked/` 解包程序。初次安装依赖和构建需要下载 Electron/NSIS；这与安装后的离线阅读无关。

```text
electron/        主进程、受限 IPC 与 preload
src/             阅读界面、Markdown 渲染和样式
build/           NSIS 自定义文件关联页面
scripts/         真实 Electron 验收、第三方许可生成
samples/         中文、空格路径、图表、公式及安全样例
QA.md            验收范围
test-results/    自动生成的测试报告和窗口截图
```

测试已安装程序：在 PowerShell 设置 `$env:MD_VIEWER_EXE='安装目录\墨阅.exe'` 后运行 `npm test`。测试使用独立配置与样例副本，结束后关闭测试窗口。文件选择器测试模拟系统返回路径，拖入通过 Chromium 原生文件拖放接口发送，外链测试拦截系统调用验证地址。

`scripts/verify-installer.ps1` 实际操作安装器并勾选文件关联，会安装或更新当前用户的墨阅。`scripts/verify-shell-open.ps1` 通过 Windows ShellExecute 的已注册 ProgID 检查应用启动前后打开文档，不修改系统保护的默认应用选择。资源管理器双击的默认应用确认仍需用户完成。

## 开源组件

应用源码采用 MIT 许可证。借鉴 Markdown Viewer、MarkText 和 Yank Note 的阅读体验；未复制这些项目源码。直接采用 Electron、TypeScript、Vite、markdown-it、markdown-it-task-lists、highlight.js、KaTeX、Mermaid、DOMPurify、Noto Sans SC 等开源组件。完整生产依赖许可见自动生成的 `THIRD-PARTY-NOTICES.txt`；Electron/Chromium 的许可证随运行时分发。构建使用 electron-builder、验收使用 Playwright。

1.1.0 支持编辑、Ctrl+S 保存、关闭前保存提示、重新载入与保存冲突确认；夜间主题采用深灰背景和蓝紫色强调。未提供同步、账号、插件或 PDF 导出。

1.1.1 的日间主题采用浅灰白底与蓝紫色强调，日间和夜间均不再使用绿色界面配色。
