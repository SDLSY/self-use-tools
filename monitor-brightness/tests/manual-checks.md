# 人工复验

1. 双击根目录 MonitorBrightness.exe。在通知区域或“显示隐藏的图标”中找到蓝色显示器图标。
2. 左键点击，面板应打开；点击其他窗口应收起。再次点击应能打开。点击面板右上角关闭后，也应能再次打开。
3. 再次双击 EXE，应打开已有面板，任务管理器中只保留一个 MonitorBrightness.exe 进程。
4. 右键托盘图标，选择“刷新显示器”，面板应显示当前读数；选择“退出”，进程和图标应消失。
5. 记下硬件亮度，微调 1–2%。成功时应显示“已读取确认”；若显示器不应用写入，应显示错误并停用滑块，悬停错误文字查看详情。刷新恢复滑块，结束后恢复原值。
6. 测试拔掉并重新连接外接屏，刷新后应重新识别。拔插未在本次验证中实际执行。
7. 若 AOC 始终读回 70，请检查显示器 OSD 的 DDC/CI、DCR、节能或游戏预设；也可以从 OSD 手动改变亮度后刷新，检查 DDC 读数是否随之变化。

如系统托盘曾保留已退出进程的旧图标，将鼠标移过图标后通常会清理；应点击当前运行进程对应的新图标。
