# PPTX Viewer for Orca

在 Orca 编辑器标签页中直接高保真浏览 `.pptx` / `.ppt` 演示文稿。

## 功能特性

- **双引擎混合渲染**
  - **浏览器内即刻解析**：基于原生 `DecompressionStream` 与 DrawingML XML 解析，打开后数十毫秒内即呈现缩略图、文本与版面预览。
  - **LibreOffice + Poppler 高清像素渲染**：后台 Worker 零拷贝定位工作区文件（外部文件自动分片传输）并按可配置 DPI（默认 180 DPI）渲染缓存，完成后无缝切换至与 PowerPoint 一致的高保真画面。
- **完整阅览工具栏**
  - 左侧可折叠缩略图胶片条
  - 键盘翻页（`←` / `→` / `↑` / `↓` / `Space` / `Home` / `End`）
  - 缩放与适应窗口（`Ctrl +` / `Ctrl -` / `Ctrl 0` / `Ctrl + 滚轮`）
  - 网格总览（`G`）、演讲备注与文字提取抽屉（`N`）、全屏演示模式（`F` / `Esc`）
  - 高清视图与可复制文字结构视图一键切换，以及单页导出图片
- 自动跟随 Orca 浅色 / 深色主题
