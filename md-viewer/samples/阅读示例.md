# 墨阅：本地阅读示例

这是一份 **中文 Markdown** 样例。所有字体、公式与图表均在本地渲染。

> 阅读不应改变原文。墨阅只读打开文件，不会保存或改写文档。

## 常用语法

- [x] 中文、空格路径
- [x] 表格、删除线与任务列表
- [ ] 远程图片需要网络

~~删除的内容~~，以及 `行内代码`。

| 本地图片 | 支持 |
| 多标签阅读 | 支持 |
